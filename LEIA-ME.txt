MATRIZ MULTI SKILL — VERSÃO LOCAL

Como executar:
1. Extraia o arquivo ZIP.
2. Abra o arquivo index.html com duplo clique em qualquer navegador moderno.
3. Use os botões Funcionário e Operação para cadastrar entradas.
4. Clique no nome do funcionário ou no código da operação para editar.
5. Clique no X para remover uma entrada.
6. Altere qualquer célula da matriz para definir Titular, Nível 1, Nível 2, Nível 3, formação planejada ou sem habilitação.

Múltiplas tabelas:
Na seção “Mapa de habilitações”, use o seletor “Tabela” para alternar entre matrizes. Clique em “＋ Nova tabela” para criar uma matriz independente. Cada tabela possui seus próprios funcionários, operações, habilitações, linhas de montagem, alocações e rotas. Use “Renomear” ou “Remover” para administrar a tabela ativa. O sistema mantém pelo menos uma tabela.

Distribuição da linha:
1. Abra “Distribuição da linha” no menu lateral.
2. Use “＋ Nova linha” para cadastrar cada linha de montagem e o seletor para alternar entre elas.
3. Aloque os montadores nos steps. A mesma pessoa não pode ocupar dois steps dentro da mesma linha.
4. Para definir uma rota personalizada, arraste os cartões de step do funcionário até a ordem desejada. A sequência será usada na rotação manual e automática.
5. Configure a data, a frequência e o modo automático. Quando a data vencer e a página estiver aberta, a rotação será executada automaticamente.
6. A rotação escolhe outro step habilitado e não mantém o funcionário no mesmo step em duas rotações consecutivas quando houver alternativa válida. Ele poderá voltar ao step anterior em uma rotação posterior.

Persistência e transferência:
As alterações são salvas automaticamente no localStorage deste navegador. Para levar os dados a outra máquina, clique em “Exportar JSON”. Na outra máquina, abra index.html, clique em “Importar JSON” e selecione o arquivo. O JSON inclui todas as tabelas, linhas, alocações, habilitações e rotas personalizadas.

Importante:
Esta versão foi feita para uso local e não possui autenticação real de servidor. A rotação automática depende de o index.html permanecer aberto; com o navegador completamente fechado, nenhuma rotina local pode ser executada.
