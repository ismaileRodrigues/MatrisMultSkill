MATRIZ MULTI SKILL — VERSÃO LOCAL

Como executar:
1. Extraia o arquivo ZIP.
2. Abra o arquivo index.html com duplo clique em qualquer navegador moderno.
3. Use os botões Funcionário e Operação para cadastrar entradas.
4. Clique no nome do funcionário ou no código da operação para editar.
5. Clique no X para remover uma entrada.
6. Altere qualquer célula da matriz para definir Titular, Nível 1, Nível 2, Nível 3, formação planejada ou sem habilitação.

Múltiplas tabelas:
Na seção “Mapa de habilitações”, use o seletor “Tabela” para alternar entre matrizes. Clique em “＋ Nova tabela” para criar uma matriz independente. Cada tabela possui seus próprios funcionários, operações, habilitações, linhas de montagem, alocações e rotas. Use “Renomear” ou “Remover” para administrar a tabela ativa. O sistema mantém pelo menos uma tabela.

Distribuição da linha:
1. Abra “Distribuição da linha” no menu lateral.
2. Use “＋ Nova linha” para cadastrar cada linha de montagem e o seletor para alternar entre elas.
3. Aloque os montadores nos steps. A mesma pessoa não pode ocupar dois steps dentro da mesma linha.
4. No painel “Programação semanal”, use os campos de segunda-feira a sexta-feira para escolher o step apto de cada funcionário em cada dia. O step em que o funcionário está alocado aparece destacado com a etiqueta “ATUAL”; funcionários sem alocação mostram “Sem alocação atual”.
5. Configure a data, a frequência e o modo automático. Quando a data vencer e a página estiver aberta, a rotação será executada automaticamente.
6. A rotação considera a programação do dia da semana, busca a maior cobertura possível da linha e usa as demais skills aptas como alternativa quando há conflito. O histórico do ciclo continua evitando repetições prematuras. Um step só fica vazio quando não existe funcionário apto disponível para ele.
7. Use “✦ Sugerir distribuição” para gerar uma prévia da melhor distribuição da linha ativa. O sistema prioriza maior nível de competência, mantém alocações existentes quando possível, não repete funcionários em dois steps e deixa vazio o step sem montador habilitado disponível. A sugestão só altera a linha depois de clicar em “Aplicar sugestão”; a alocação manual continua disponível a qualquer momento.

Persistência e transferência:
As alterações são salvas automaticamente no localStorage deste navegador. Para levar os dados a outra máquina, clique em “Exportar JSON”. Na outra máquina, abra index.html, clique em “Importar JSON” e selecione o arquivo. O JSON inclui todas as tabelas, linhas, alocações, habilitações, rotas personalizadas e o progresso dos ciclos. A importação aceita UTF-8 com ou sem BOM e mantém compatibilidade com exportações anteriores.

Importante:
Esta versão foi feita para uso local e não possui autenticação real de servidor. A rotação automática depende de o index.html permanecer aberto; com o navegador completamente fechado, nenhuma rotina local pode ser executada.
